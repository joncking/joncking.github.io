[View the public repository](https://github.com/joncking/agentspace-public)

Agentspace is a Kubernetes-native platform for turning reusable `AgentTemplate`
specialists into private `Workspace` runtimes. It snapshots selected catalog
agents into isolated Kubernetes namespaces, adds workspace-local artifact
storage, and creates a generated orchestrator so users can chat with a
coordinated specialist team.

The project includes CRDs and controllers, Helm packaging, a local `k3d`
quickstart, built-in skills and artifact tooling, Jaeger tracing, and a small
CLI for workspace inspection, logs, and chat.
